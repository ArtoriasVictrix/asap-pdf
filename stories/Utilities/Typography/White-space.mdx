# White space

The `text-wrap` and `text-nowrap` utilities set how
[white space](https://developer.mozilla.org/en-US/docs/Web/CSS/white-space) inside an element is handled.

## Sass

### Utilities API

White space utility is declared in the utilities API in `app/scss/_utilities.scss`.
[Learn how to use the utilities API on the Bootstrap website](https://getbootstrap.com/docs/5.1/utilities/api/#using-the-api).

```
'white-space': (
	property: white-space,
	class: text,
	values: (
		wrap: normal,
		nowrap: nowrap
	),
),
```
