# Object position

[Object position](https://developer.mozilla.org/en-US/docs/Web/CSS/object-position) utilities control how a replaced
element's content should be positioned within its container.

## SCSS (Sass)

### Utilities API

Object position utilities are declared in the utilities API in `app/scss/_utilities.scss`.
[Learn how to use the utilities API on the Bootstrap website](https://getbootstrap.com/docs/5.1/utilities/api/#using-the-api).

```
'object-position': (
	property: object-position,
	class: obj,
	values: (
		bottom: bottom,
		center: center,
		left: left,
		left-bottom: left bottom,
		left-top: left top,
		right: right,
		right-bottom: right bottom,
		right-top: right top,
		top: top,
	)
),
```
