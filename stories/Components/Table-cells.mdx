# Table cells

## Padding

You can adjust cell padding using following classes:

- `cell-p-N`
- `cell-px-N`
- `cell-py-N`

`N` — the padding value in increments of 4px.

You can apply padding classes to cells, table rows, and even the whole table.

## Vertical alignment

Vertical alignment of content in the table cells is set with the help of classes:

- `cells-va-bl` (baseline)
- `cells-va-t` (top)
- `cells-va-m` (middle)
- `cells-va-b` (bottom)
- `cells-va-tb` (text-bottom)
- `cells-va-tt` (text-top)
