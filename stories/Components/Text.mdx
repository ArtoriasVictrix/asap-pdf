# Text components

In addition to utilities for setting `font-size` ([.fz-N](?path=/story/utilities-typography-font-size--page)),
`font-weight` ([.fw-N](?path=/story/utilities-typography-font-weight--page)), and `line-height`
([.lh-N](?path=/story/utilities-typography-line-height--page)), ASAP PDF includes a list of ready-to-use text
components. We structured them in a way that looks neat and made sure you don’t have to select the appropriate CSS
property values yourself.
